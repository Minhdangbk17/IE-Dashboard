Rebuild Summaries

Recomputes the Daily Rollup summary tables (Downtime, Batch/Day Matrix, Cleaning MC, ...) straight from raw data. Use this after a schema/formula change, or to backfill history after adding a new filter column — same as running flask rebuild-summaries, but runs on this server (useful when your own machine can't reach the database directly, e.g. behind a firewall).

Leave both blank to rebuild the entire history in one run. If that times out, narrow the date range and run it a few times to cover the full history in batches — each run is safe to repeat.
